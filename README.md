# 期权分析工具使用指南

## 📋 功能概览

这是一个完整的期权分析和风险管理平台，包含以下主要功能：

### 1. **ETF K线图表** 📈
- 显示ETF基金的日K线图表
- 支持多个ETF标的切换
- 实时显示开、高、低、收价格

### 2. **T型报价表** 💱
- **行情模式**：显示现价、涨跌幅、成交量、持仓量
- **价值模式**：显示隐含波动率(IV)、历史波动率(HV)、时间价值、内在价值
- **风险模式**：显示Greeks风险指标（Delta、Gamma、Vega、Theta、Rho）
- **合约模式**：显示合约乘数、到期时间、期权类型（欧式/美式）、合约代码
- 按行权价排列，看涨和看跌期权并列显示
- 支持月份切换

### 3. **期权详情分析** 📊
- 选中期权后显示日K线图表
- 显示关键指标：合约代码、行权价、当前价、隐含波动率、历史波动率等
- 计算内在价值和时间价值

### 4. **期权组合构建** 🎯
- 从T型报价表中选择期权添加到组合
- 支持买入/卖出方向选择
- 支持多张合约组合
- 实时绘制组合损益图（P&L图）

### 5. **损益图分析** 📈
- 动态计算期权组合在不同标的价格下的损益
- 展示组合的风险收益特征
- 支持看涨、看跌、马鞍等多种组合策略

### 6. **价格预测** 🔮
- 基于对数正态分布的股票价格预测
- 支持3天、5天、10天多个预测周期
- 显示预测价格、标准差、95%置信区间
- 计算价格上升概率
- 绘制概率分布图

## 🚀 使用指南

### 启动应用
1. 在浏览器中打开 `index.html` 文件
2. 或者在本地起一个简单的HTTP服务器：
   ```bash
   python -m http.server 8000
   # 然后访问 http://localhost:8000/index.html
   ```

### 数据加载
#### 方法1：上传CSV文件
1. 点击"📂 加载数据"区域
2. 选择三个CSV文件：
   - `option_info.csv`：期权合约信息
   - `option_price.csv`：期权价格数据
   - `etf_price.csv`：ETF价格数据
3. 点击"📂 加载数据"按钮

#### 方法2：使用示例数据
- 点击"📋 使用示例数据"按钮，自动生成示例数据

### 使用流程

#### 第一步：查看ETF行情
1. 在左侧"ETF K线图"选择不同的ETF标的
2. 查看对应的日K线走势

#### 第二步：查看期权报价
1. 在"T型报价表"中选择不同的月份
2. 点击不同的选项卡查看不同类型的数据：
   - **行情**：基础报价信息
   - **价值**：期权定价相关指标
   - **风险**：风险希腊字母
   - **合约**：合约基本信息

#### 第三步：选择单个期权
1. 点击T型报价表中的期权名称
2. 下方会显示该期权的：
   - K线图表
   - 详细指标卡片
   - 内在价值和时间价值

#### 第四步：构建期权组合
1. 选择一个期权后，点击"➕ 添加到组合"
2. 选择操作方向（买入/卖出）和数量
3. 点击"确定"添加到组合
4. 右侧"期权组合构建"区域会：
   - 列出已添加的合约
   - 绘制组合损益图
5. 可继续添加多张合约形成复杂组合

#### 第五步：分析价格预测
1. 在"股票价格预测"区域选择预测天数（3/5/10天）
2. 系统会显示：
   - 预测价格（均值）
   - 标准差
   - 95%置信区间
   - 价格上升概率
   - 概率分布曲线

## 📊 数据格式说明

### option_info.csv
期权合约信息表，包含以下关键字段：
- `symbol`: 期权名称
- `underlying_symbol`: 标的资产代码
- `strike_price`: 行权价
- `maturity_date`: 到期日期
- `option_type`: 期权类型（C=看涨/P=看跌）
- `exercise_type`: 行权类型（E=欧式/A=美式）
- `contract_multiplier`: 合约乘数
- `order_book_id`: 交易所订单ID

### option_price.csv
期权价格数据表，包含以下关键字段：
- `date`: 交易日期
- `code`: 期权代码
- `open`: 开盘价
- `close`: 收盘价
- `high`: 最高价
- `low`: 最低价
- `volume`: 成交量
- `money`: 成交金额
- `position`: 持仓量

### etf_price.csv
ETF价格K线数据表，包含以下关键字段：
- `time`: 交易日期
- `code`: ETF代码
- `open`: 开盘价
- `close`: 收盘价
- `high`: 最高价
- `low`: 最低价
- `volume`: 成交量
- `money`: 成交金额

## 🔧 技术指标说明

### 隐含波动率 (IV - Implied Volatility)
- 通过Black-Scholes模型反推的波动率
- 反映市场对未来波动率的预期
- IV越高，期权价格越贵

### 历史波动率 (HV - Historical Volatility)
- 基于过去价格变动计算的波动率
- 使用收益率的标准差计算
- 年化波动率 = 日波动率 × √252

### 内在价值 (Intrinsic Value)
- 看涨期权：max(S - K, 0) × 乘数
- 看跌期权：max(K - S, 0) × 乘数
- S: 标的当前价格，K: 行权价

### 时间价值 (Time Value)
- 期权价格 - 内在价值
- 反映期权中的时间成本
- 随着到期日临近而衰减（Theta）

### Greeks风险指标
- **Delta (Δ)**: 期权价格对标的资产价格的敏感度
- **Gamma (Γ)**: Delta对标的资产价格的敏感度
- **Vega (ν)**: 期权价格对波动率的敏感度
- **Theta (θ)**: 期权价格对时间的敏感度（时间衰减）
- **Rho (ρ)**: 期权价格对利率的敏感度

## 💡 常见策略

### 1. 买入看涨期权 (Long Call)
- 适合看好后市的投资者
- 风险有限（最多亏掉权利金），收益无限
- 通过组合损益图查看具体的收益曲线

### 2. 买入看跌期权 (Long Put)
- 适合看空后市或对冲风险的投资者
- 风险有限（最多亏掉权利金），收益有限但稳定

### 3. 看涨期权差价 (Bull Call Spread)
- 买入低行权价看涨 + 卖出高行权价看涨
- 降低期权成本，限制最大收益
- 适合中性偏看好的市场

### 4. 跨式组合 (Straddle)
- 买入相同行权价的看涨 + 看跌期权
- 适合预期大幅波动的市场
- 无论价格向上还是向下都有利润

## 📝 常见问题

### Q: 如何导出报表？
A: 当前版本不支持直接导出，但可以使用浏览器的截图和打印功能。

### Q: 数据如何更新？
A: 重新上传最新的CSV文件或点击"使用示例数据"重新加载。

### Q: Greeks风险指标是如何计算的？
A: 使用Black-Scholes欧式期权定价模型计算，基于日收益率标准差估计波动率。

### Q: 价格预测的准确性如何？
A: 这是基于对数正态分布的统计预测，仅供参考。实际市场价格受多种因素影响，不能完全预测。
