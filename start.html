📊 期权分析工具

完整的期权行情分析、组合构建和风险评估平台

🎯 主要功能

ETF K线图表
T型报价表（4种模式）
期权详情分析
期权组合构建
损益图（P&L）
Greeks风险指标
价格预测分析
CSV数据导入

第一步：准备工作

确保工作目录中包含以下文件：

index.html - 主应用界面
app.js - 应用逻辑
option_info.csv - 期权合约信息
option_price.csv - 期权价格数据
etf_price.csv - ETF价格数据

第二步：启动应用

方法1：直接打开

双击 index.html 文件，在浏览器中打开。

方法2：启动本地服务器（推荐）

如果在Windows上，进入文件夹后执行：

python -m http.server 8000

然后在浏览器中访问：http://localhost:8000

第三步：加载数据

应用启动后，选择一种方式加载数据：

• 使用示例数据：点击"📋 使用示例数据"按钮，自动生成演示数据

• 上传CSV文件：选择三个数据文件，点击"📂 加载数据"

第四步：开始分析

✅ 查看ETF K线图表

✅ 浏览T型报价表（切换月份和显示模式）

✅ 选择期权查看详情和K线图

✅ 构建期权组合和分析损益

✅ 查看价格预测和概率分布

⚠️ 注意事项：
  • 请使用现代浏览器（Chrome、Firefox、Safari、Edge）
  • 确保浏览器启用了JavaScript
  • 本工具仅供学习和研究使用，不构成投资建议
✅ 系统要求：
  • 现代浏览器（Firefox、Chrome、Safari、Edge）
  • JavaScript 支持（ES6+）
  • 本地存储功能
